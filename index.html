☁️ Synchronisation et déploiement

Les données sont synchronisées entre tous les appareils via Firebase. Ne saisissez jamais de mot de passe dans cette page.

Synchronisation : non configurée

Le paquet ZIP contient l'application (avec la configuration Firebase enregistrée), les fichiers Netlify et les règles Firestore.

Étapes Firebase et règles de sécurité
  1. Console Firebase : créer un projet, puis ajouter une application Web.
  2. Authentication : activer le fournisseur « Anonyme ».
  3. Cloud Firestore : créer la base, puis coller les règles ci-dessous dans l'onglet Règles.
  4. Copier l'objet firebaseConfig dans la zone ci-dessus.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /etatnotes/{document} {
      allow read, write: if request.auth != null;
    }
  }
}
